SECTION 01  ·  NEW COPILOT  ·  9월 25일 발표
Home · Code · Autopilot으로 새로워진 Copilot
Copilot 앱에 세 가지 새로운 기능 추가
Home Copilot의 새로운 시작점 — Chat과 Cowork를 한곳에서 이용. Office in Copilot으로 Word · Excel · PowerPoint 기능을 Copilot 안에서 바로 활용
Chat은 빠른 질문 · 검색 · 초안 작성, Cowork는 위임한 업무를 처음부터 끝까지 수행해 완성된 결과물 제공
Frontier 프로그램을 통해 향후 몇 주에 걸쳐 순차 제공
Code 누구나 만드는 맞춤형 솔루션 — 앱 · 트래커 · 대시보드 · 자동화 · 워크플로를 자연어로 설명하면 Copilot이 구축
GitHub Copilot과 동일한 기반 기술 · 샌드박스 환경에서 실행, 조직 테넌트 내 호스팅 가능
Copilot Managed Runtime(프리뷰): 조직의 Microsoft 365 환경 안에서 코드를 안전하게 실행하는 호스팅 인프라 — IT가 관리
9월 말 Frontier 제공 시작, 이후 몇 주 내 확대 예정
Autopilot 항상 일하는 개인형 에이전트(기존 Microsoft Scout) — 이름 · 역할 · 목표를 정하면 채널 확인, 후속 조치, 반복 업무, 며칠 전 멈춘 프로젝트 재개까지 별도 요청 없이 수행
클라우드에서 구동 · 테넌트 안에서 자체 ID · 메모리 · 작업 공간 보유, Microsoft IQ 기반
Teams · Outlook 등에서 @멘션으로 호출 — 권한 관리 · 감사 · 거버넌스 적용
9월 말 비공개 프리뷰 확대
AI 비용 관리 FinOps for AI — Agent 365 · Insights · Copilot 전반에 비용 관리 기능 추가
관리자: 지출 정책 관리, 크레딧 요청 승인 흐름 연계, 사용자 그룹별 사용 가능 모델군 설정
리더: 어떤 Cowork 작업이 성과를 내는지 파악해 확대 · 최적화 판단
사용자: Copilot에서 크레딧 사용량 · 잔액 · 이력 직접 확인
요금 구조: 일상 업무는 사용자 라이선스(USL), Cowork · Code · Autopilot과 프론티어 모델은 사용량 기반 과금(UBB)
CxO 시사점 AI 활용 단위가 ‘질문 한 번’에서 ‘목표 하나’로 커집니다. 현업이 직접 만드는 앱 · 에이전트가 늘어나는 만큼 어디서 만들고, 누가 승인하며, 비용을 어떻게 배분할지에 대한 사내 기준이 먼저 필요합니다.

SECTION 02  ·  CONTEXT LAYER
Microsoft IQ — 기업 AI를 위한 통합 인텔리전스 계층
Copilot과 에이전트가 ‘우리 회사’를 이해하는 기반
Microsoft IQ란 Microsoft가 제시하는 엔터프라이즈 AI를 위한 통합 인텔리전스 계층 — 모든 에이전트와 Copilot이 조직에 대한 공유되고 지속적으로 업데이트되는 이해를 바탕으로 작동합니다.
4가지 IQ
Work IQ업무를 이해 — 사람 · 협업 · 워크플로
Fabric IQ비즈니스를 이해 — 비즈니스 엔터티 · 관계 · 규칙
OneLake 통합 데이터 · Power BI 시맨틱 모델 · 온톨로지 3개 계층
Foundry IQ지식을 이해 — 정책 · 신뢰할 수 있는 문서 · 재사용 가능한 지식 베이스
Web IQ외부 세계를 이해 — 웹 전반의 최신 실시간 정보
이번 발표 새로운 Copilot은 Microsoft IQ를 기반으로 활용 가능한 비즈니스 맥락을 확대했습니다.
Fabric IQ: Chat · Cowork에 정식 제공 — 조직 데이터의 신뢰할 수 있는 맥락을 Copilot에 연결 (Code 연동은 Frontier 예정)
Dynamics 365 · Power Platform: 데이터와 워크플로 기반 작동 — 퍼블릭 프리뷰로 순차 제공
플러그인 레지스트리: Microsoft · 파트너 · 자체 개발 플러그인을 하나의 카탈로그로 — IT가 중앙에서 승인 · 관리
CxO 시사점 AI 답변의 품질은 모델만이 아니라 ‘얼마나 우리 회사를 아는가’에서 갈립니다. 업무(Work) · 비즈니스 데이터(Fabric) · 사내 지식(Foundry) · 외부 정보(Web)가 하나의 계층으로 연결되므로, 흩어진 데이터와 문서를 정리하고 거버넌스를 갖추는 일이 곧 AI 경쟁력입니다.

SECTION 03  ·  WINDOWS  ·  10월 7일 발표
Windows Hybrid Intelligence = Local + Cloud AI
에이전트가 로컬과 클라우드를 오가며 안전하게 일하는 플랫폼
무엇이 Windows를 하이브리드 인텔리전스 플랫폼으로 — 에이전트가 적합할 때는 로컬에서, 필요할 때는 클라우드를 활용하며, 기업이 요구하는 보안 · 관리 체계 안에서 작동
Copilot + Windows Copilot+ PC에서 사용자 허가를 전제로 세 가지 로컬 기능 제공
로컬 컨텍스트: PC의 파일 · 최근 활동 이해
로컬 작업: 파일 정리, 디바이스 진단 · 문제 해결, 코딩, 워크플로 수행
로컬 모델: PC의 AI 모델을 활용하고, 필요 시 클라우드와 결합
향후 몇 달에 걸쳐 Copilot+ PC에 순차 제공 (기기 · 시장별 상이)
왜 로컬인가 AI 수요가 클라우드 예산이 감당할 수 있는 속도보다 빠르게 늘고 있습니다. 로컬 AI와 클라우드 AI를 결합해 필요한 역량은 유지하면서 토큰 · 예산을 효율적으로 사용
GitHub HydraFusion이 작업별로 로컬 · 클라우드 모델을 라우팅 (10월 말 실험적 프리뷰 예정)
보안 설계 Microsoft Execution Containers(MXC) 정식 출시 — 조직이 에이전트가 접근할 수 있는 파일 · 네트워크를 정의하면 실행 시점에 정책을 강제
Windows의 에이전트 보안 3원칙: 격리(Containment) · ID(어떤 에이전트가 작업했는지) · 관리(Agent 365 · Intune 연동)
이미 지원: OpenAI Codex, GitHub Copilot, OpenClaw, Replit, LM Studio 등 · 지원 예정: Anthropic Claude Code, Perplexity 등
새로운 PC NVIDIA RTX Spark 기반 Windows PC 예약 판매 시작 — Surface Laptop Ultra(최대 128GB 통합 메모리) 및 ASUS · Dell · HP · Lenovo · MSI
데스크사이드 AI 슈퍼컴퓨터 DGX Station for Windows는 연내 출시 예정
출시 시점 · 제공 국가는 기기 · 시장별로 다를 수 있음
CxO 시사점 AI를 ‘어디서 처리할 것인가’가 경영 선택지가 됩니다. 적합한 작업은 로컬에서, 고난도 작업은 클라우드에서 — 향후 PC 교체 계획과 AI 비용 계획을 함께 보셔야 합니다.
