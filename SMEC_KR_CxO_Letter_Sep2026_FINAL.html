01 + 02 의 공통 기반
두 공식 발표문에 토씨까지 같은 문장이 들어 있습니다
“Work IQ가 이 모델을 여러분의 파일 · 회의 · 채팅 · 비즈니스 데이터에 — 기존 권한 범위 안에서 — 접지시켜, 프롬프트만이 아니라 실제 업무 위에서 추론하게 합니다. 그 결과 더 관련성 높고 정확한 답변이 나오며, 출처를 업무 원본까지 되짚어 확인할 수 있습니다.”
“AI가 우리 회사를 모른다” 업무 데이터 위에서 추론
“권한이 샐까 두렵다” 기존 권한 범위 안에서만 접근
“답을 믿을 수 없다” 원본까지 출처 추적 가능
→ 모델은 갈아끼우고, 권한 설계 · 업무 맥락 · 출처 추적은 회사에 남습니다.
SECTION 03  ·  NEW CAPABILITY  ·  FRONTIER PREVIEW
PowerPoint Interactive Skills
선형 슬라이드 → 클릭해 탐색하는 반응형 프레젠테이션
무엇이 PowerPoint가 선형 슬라이드에서 클릭해 탐색하는 반응형 프레젠테이션으로 확장
사용법 Interactive Skills를 선택하고 소스 데이터를 넣기만 하면 동작 — 별도 코딩 불필요
왜 다른가 기존 PowerPoint는 구조상 선형 시나리오 — 경우의 수마다 장표를 만들고 발표 중 복잡하게 이동해야 했습니다.
Interactive는 반응형이라 선형 설계 자체가 불필요합니다. 가장 유사한 경험은 Power BI이며, 데이터에 맞는 차트를 추천합니다.
유의 사항 새로 도입된 기능이라 발표 시 선택 방식과 편집 방법(Copilot 사용)에 익숙해지는 과정이 필요합니다. 현재 Frontier Preview 단계입니다.
CxO 시사점 임원 보고와 이사회 자료가 ‘미리 정한 순서’에서 ‘질문에 답하는 자료’로 바뀝니다. “그 수치 근거는?”에 그 자리에서 답할 수 있습니다.
